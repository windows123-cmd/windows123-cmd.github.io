El Desafío de las Ciudades Saludables

Las áreas urbanas enfrentan problemas críticos que afectan la calidad de vida de sus habitantes. Los datos espaciales permiten identificar las soluciones.

Diagnóstico y Soluciones Basadas en Datos

El desafío "Data Pathways to Healthy Cities and Human Settlements" de NASA Space Apps invita a urbanistas, planificadores y comunidades a utilizar datos abiertos para abordar problemas urbanos críticos.

Mediante el análisis de datos de calidad del aire, temperatura superficial, cobertura vegetal, accesibilidad a servicios y software como QGis(ecosistemas amenazados, humedales, aréas protegidas) podemos identificar áreas de mejora y diseñar intervenciones efectivas.

Nuestra plataforma facilita el acceso a estos datos y proporciona herramientas para su análisis, ayudándote a crear ciudades más habitables, equitativas y resilientes.

Tipos de Datos Disponibles

Accede a una amplia gama de datos espaciales y terrestres para tu análisis urbano.

Isla de Calor Urbana

Datos de temperatura superficial de Landsat y MODIS para identificar y cuantificar el efecto de isla de calor en diferentes zonas urbanas.

NASA Worldview

Espacios Verdes

Información sobre cobertura vegetal mediante índices NDVI de Sentinel-2 y Landsat para evaluar la distribución de áreas verdes.

NASA Earth Observatory

Calidad del Aire

Datos de contaminantes atmosféricos (NO2, CO, aerosoles) de instrumentos como TROPOMI y GEOS-CF de la NASA.

NASA Earthdata Search

Asentamientos Humanos

Datos globales sobre distribución de población, densidad de construcciones y expansión urbana.

Copernicus GHSL

Datos Demográficos

Información de alta resolución sobre distribución poblacional, dinámica y características demográficas.

WorldPop

Indicadores Educativos
